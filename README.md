# donor-segmentation-clustering
Unsupervised Machine Learning project for donor segmentation using clustering techniques, PCA, feature engineering, and exploratory data analysis.

This project applies unsupervised machine learning techniques to identify meaningful donor segments from a nonprofit organization's historical fundraising data.

The objective is to uncover hidden donor profiles that can help charities improve fundraising campaigns through personalized outreach and data-driven decision-making.

The project was completed as part of the Data Science & Machine Learning course at NOVA IMS – Universidade Nova de Lisboa, where the assignment focused on using clustering techniques to analyze donor behavior and support targeted fundraising strategies
